# Netflix Content Analysis

**Exploratory analysis of the Netflix Movies and TV Shows catalog to identify content mix, release patterns, genres, duration, and geographic distribution.**

## At a glance

| Area | Analysis |
|---|---|
| Content mix | Movies vs. TV Shows |
| Time trends | Release-year and catalog growth patterns |
| Genres | Genre frequency and distribution |
| Geography | Country-level content distribution |
| Duration | Movie runtime and title characteristics |

## Dataset

The project uses the **Netflix Movies and TV Shows** dataset containing approximately **8,800 titles** and 12 columns, including title, type, country, release year, listed-in categories, and duration.

## Technical workflow

**Python → Pandas / NumPy → Data cleaning → Exploratory analysis → Matplotlib / Seaborn → Interpretation**

## Key findings

- Movies make up the larger share of titles in the analyzed catalog.
- Content additions increased substantially in the later years represented in the dataset.
- Drama and international categories appear frequently across the catalog.
- Movie durations cluster around the typical feature-film range, with variation across titles.

> Findings are specific to the supplied dataset and its time coverage; they should not be interpreted as current Netflix catalog statistics.

## Analysis covered

- Content-type distribution
- Release-year trends
- Genre/category analysis
- Country distribution
- Movie duration analysis
- Distribution and trend visualizations

## Run locally

Open **Netflix_Analysis.ipynb** in Jupyter Notebook or JupyterLab after installing the Python data-analysis libraries.

The dataset is included as **netflix_titles.csv**.
