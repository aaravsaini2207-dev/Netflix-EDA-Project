Exploratory Data Analysis of Netflix Movies and TV Shows using Python

# Netflix Content Analysis

## Overview
This project performs exploratory data analysis on Netflix’s catalog to uncover trends in content type, duration, genres, countries, and release patterns.

## Dataset
- Source: Kaggle (Netflix Movies and TV Shows)
- Rows: ~8,800
- Columns: 12

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Insights
- Movies dominate Netflix’s catalog
- Average movie duration is ~100 minutes
- Content growth accelerated after 2016
- Drama and International genres are most common

## Conclusion
This analysis provides insights into Netflix’s content strategy and global distribution.
